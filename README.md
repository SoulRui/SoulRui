## 你好，我是 SoulRui / Hi, I'm SoulRui

我专注于制作真正解决日常问题的 Windows 小工具，方向包括 **GIS、无人机影像、照片处理和文件自动化**。

I build practical Windows tools for GIS, drone imagery, photo processing, and file automation — with a focus on **local processing, privacy, and useful outcomes**.

- **本地优先 / Local-first**：核心处理尽量在本机完成。
- **隐私优先 / Privacy-first**：公开示例使用虚构数据，敏感路径、地名和坐标会脱敏。
- **统一体验 / Consistent design**：应用图标遵循 **MC Software Visual Identity System V1.0**。
